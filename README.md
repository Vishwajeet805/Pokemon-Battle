# Pokémon Battle

Fresh Next.js + TypeScript foundation for a browser-based Pokémon card and 3D battle game.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current prototype
- Responsive trainer dashboard
- Three.js / React Three Fiber 3D practice arena
- Six-Pokémon battle team selector
- Practice battle moves and HP updates
- Pokémon artwork loaded from the PokeAPI sprites repository

## Next milestones
1. Full Pokédex search and persistent collection
2. Card rarity, CP, movesets, type chart and turn-based battle engine
3. GLB/GLTF model pipeline with asset source/license metadata
4. Trainer profiles, multiplayer rooms and matchmaking
5. Packs, evolution, raids, gyms and progression
